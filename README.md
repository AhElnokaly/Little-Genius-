# ألعاب طفلي الذكي (Little Genius) - Android Application

تطبيق أندرويد تعليمي تفاعلي متكامل للأطفال مبني بلغة **Kotlin** وأحدث تقنيات **Jetpack Compose** و **Material Design 3**.

## الميزات الرئيسية (Core Features)

1. **الحروف والأرقام 🔢**:
   - **حروف عربي**: تعلم الحروف الهجائية الثمانية والعشرين مع أمثلة ونطق صوتي واضح.
   - **تشكيل الحروف**: تدريب تفاعلي على الفتحة والضمة والكسرة والسكون.
   - **تكوين الكلمات**: تكوين كلمات بسيطة بسحب ولمس الحروف.
   - **حروف English**: الأبجدية الإنجليزية A-Z مع الكلمات والصوتيات.
   - **حروف وحيوانات**: مطابقة الحرف الأول مع الحيوان المناسب.
   - **أرقام 123**: الأرقام ثنائية اللغة (عربي وإنجليزي) مع العد البصري.
   - **عد الأشياء**: ألعاب تفاعلية لعد العناصر واختيار الرقم الصحيح.
   - **حساب بسيط**: عمليات جمع وطرح مبسطة للأطفال الصغار.

2. **عالمي الصغير 🌍**:
   - **بيتي الجميل**: استكشاف غرف المنزل (غرفة النوم، المطبخ، الحمام، غرفة الجلوس) ومحتوياتها.
   - **أكل صحي**: فرز الأطعمة الصحية والمفيدة مقابل الحلويات.
   - **عائلات الحيوانات**: مطابقة الحيوان الأم مع صغيرها.
   - **أصدقاء الحيوانات**: استماع لأصوات حقيقية لأكثر من 20 حيواناً ونطق أسمائها.
   - **خمن الصوت**: الاستماع إلى صوت الحيوان وتخمين صاحبه.
   - **الوقت والتقويم & الطبيعة & القمر**: مفاهيم الوقت والظواهر الطبيعية.

3. **ألعاب ومهارات 🎨**:
   - **فرقع البالونات**: بالونات متحركة ملونة مع مؤثرات الفرقعة والنجوم.
   - **الرسم السحري**: رسم حر بألوان نيون مشعة وتأثيرات ضوئية.
   - **بيانو الألوان**: 8 مفاتيح موسيقية ملونة لعزف ألحان طفولية.
   - **الأشكال الهندسية**: مطابقة وتصنيف الأشكال.
   - **كتاب الملصقات**: 3 أوضاع (لوحتي الحرة، مطابقة الظل، اسمع واختار).
   - **صيد السمك**: بحيرة متحركة لصيد الأسماك المتنوعة.
   - **لعبة الذاكرة**: تقليب بطاقات الحيوانات والبحث عن المتطابقين.

4. **إدارة الأهل والتحكم الأبوي (Parental Control & Dashboard)**:
   - **قفل الخروج (Parental Gate)**: حماية الخروج بمسائل حسابية لمنع خروج الطفل العرضي.
   - **تحديد وقت الشاشة (Screen Time Limit)**: مؤقت زمني يقفل الشاشة عند انتهاء الوقت.
   - **لوحة متابعة الآباء (Parents Dashboard)**: إحصائيات دقيقة عن الألعاب الملعوبة وإجمالي النجوم المكتسبة.
   - **تخصيص الملف الشخصي**: اختيار اسم الطفل، الأفاتار المفضل، وتاريخ الميلاد.

## الهيكلية التقنية (Tech Stack)

- **Language:** Kotlin 2.1.0
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM with Clean Architecture patterns
- **Audio Engine:** Android Native `TextToSpeech` + `MediaPlayer` (ملفات صوتية حقيقية في `res/raw`)
- **Persistence:** Repository pattern with SharedPreferences & JSON storage
- **Build System:** Gradle (Kotlin DSL) مع Version Catalog (`libs.versions.toml`)
